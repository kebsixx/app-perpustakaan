## Keterangan

- `GET /api/books` dan `GET /api/members` memakai pagination dengan 10 data per halaman; field `links` dan `meta` dihasilkan otomatis oleh Laravel.
- `POST /api/loans` mewajibkan `user_id` karena endpoint API tidak menggunakan session `auth()`, sedangkan `member_id`, `tanggal_pinjam`, `tanggal_kembali`, dan `book_ids` wajib diisi sesuai aturan validasi `Api\LoanController@store`.
- Nilai `status` pada transaksi yang baru dibuat adalah `"dipinjam"`, bukan `null`, karena controller memanggil `$loan->refresh()` sebelum memuat `LoanResource`.
- `POST /api/books` memvalidasi input melalui `StoreBookRequest`, sehingga field `judul`, `penulis`, `penerbit`, `tahun_terbit`, `stok`, dan `category_id` bersifat wajib, sedangkan `isbn` bersifat opsional.
- Pencarian `judul` bersifat case-insensitive dan mendukung pencocokan sebagian teks.
